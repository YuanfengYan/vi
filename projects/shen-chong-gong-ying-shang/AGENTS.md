# 本项目的视频生成

- 生成视频统一使用 `scripts/supervideo.py` 调用 SuperVideo Platform API。
- 账号及运行参数读取项目根目录 `.env.local`，进程环境变量优先；不交互输入，不在对话、日志或制作文档中输出密码和令牌。
- 先完成本集定稿资料，执行 `prepare --episode EP001` 核对，再在用户要求生成视频时执行 `run --episode EP001`。用户明确启动本批后自动顺序执行，不逐镜补问。
- `run` 会提交真实生成任务。仅要求修改脚本、提示词或测试时，不运行真实生成。
- 所有新写或修订的视频提示词必须使用工作区 `.agents/skills/h3-prompt-expert/SKILL.md` 及匹配 reference，可复制正文统一用英文输出，保留官方 H3 字段与素材标签；角色对白、VO、OS 和指定画内文字保留剧本中文原句，创作者说明仍用中文。
- 视频任务名称格式为 `MOTION-<集号> -第<N>段`，例如 `MOTION-EP001 -第2段`。N 按整集实际生成顺序从 1 编号，每个分镜独立计一段，禁止合生，单选提交也保留整集段号；条目 ID、文件名与历史提交记录保持原值。
- 生成时只提交并记录任务 ID，收到任务号即返回；不轮询、不等待完成、不自动下载，也不启动后台等待进程。
- 只有用户主动要求查询时才使用 `status`；只有用户主动要求下载时才使用 `collect`。`collect` 只检查一次，未完成即返回状态，不持续等待。
- 中断后用 `run` 恢复同一幂等提交；已有任务号的条目只回报原 ID，不查询、不重提。提示词语言或任务命名规则调整不会触发已提交片段重拍，历史请求保留原文。
- 当前 EP001 为 90 秒、18 镜、18 个独立任务，首帧位于「首帧90s」。最短生成时长为 3 秒，multi_shot_containers=false，所有剧集均不得合并分镜生成。
- 014、015 分别生成，后期按稳定视线硬切到纯天空；旧 015 首帧停用，015 只使用巨兽主体参考。历史 GROUP 记录仅供追溯，不再用于生成。
- 第一段执行 run --episode EP001 --entry MOTION-EP001-012（3 秒）；第二段对应 MOTION-EP001-013（3 秒）。只修改对应 MOTION 小节的可复制提示词，提交前对比上次实际正文差异。

- 后续新视频请求统一按用户指定 15 步：acceleratorEnabled=false、steps=15，禁止快速抽卡；分辨率继续按现有配置。历史提交请求不得改写。
